# Zed Configs

Personal Zed editor configuration for Linux.

This repository is the Zed config directory itself (`~/.config/zed`). The files here are loaded directly by Zed:

- `settings.json` - editor settings
- `keymap.json` - custom keybindings

## Usage

Clone this repository into `~/.config/zed`, or symlink `~/.config/zed` to your clone.

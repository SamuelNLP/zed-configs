# AGENTS.md

This repository holds the personal Zed editor configuration for Linux.

## Context

- Target platform: Linux. Zed's config directory is `~/.config/zed`, and this repository is that directory.
- The live config files are `settings.json` and `keymap.json` at the repository root.

## Rules

- Always ask the user for confirmation before making any change to files in this repository. Do not modify or create files without explicit approval.
